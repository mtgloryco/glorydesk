Documentation

Install, activate, and operate Glory Desk.

Install

  1. Download from Download.
  2. Run installer as administrator if prompted.
  3. Launch Glory Desk from Start menu.

First login

Default: admin / admin123 — change immediately under Users.

Modules by tier

Basic: Inventory only · Medium: + POS, PO · Pro: + Reports, audit · Enterprise: + Cloud sync, Enterprise hub

Data locations

  • Database: %LocalAppData%\GloryDesk\inventory.db
  • Exports: Documents\GloryDesk\
