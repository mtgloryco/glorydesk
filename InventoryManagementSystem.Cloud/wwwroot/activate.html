License activation

Each license is cryptographically signed and bound to one computer. Activate inside the Glory Desk desktop app.

Activation steps

  1. Install Glory Desk on the target Windows PC.
  2. Open the app → sidebar License.
  3. Copy your Hardware ID from that screen.
  4. Submit the form below (or email support@mtglory.com).
  5. Paste the signed key MT GLORY CO sends you → Activate License.

Request a license key

One machine per key. Hardware transfer requires support approval. Sharing keys across locations is a license violation.
